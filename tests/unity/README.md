# Unity workflow tests

These tests require the Unity Editor and Unity Test Framework. They are not
executed by the standalone C# compile check.

1. Use a disposable Unity 2020.3+ project with the 1.5.1 package installed.
2. Copy this entire folder to `Assets/MeshyWorkflowTests` (exact name).
3. Run the `MeshyWorkflowTests` EditMode tests in Window > General > Test Runner.

The fixture is synthetic Meshy data, generated by tests/meshy_fixtures.py.
Tests create uniquely named temporary asset folders and remove only their own
folders and successful-settings snapshot. They check native summary values,
remembered import settings, material override persistence and retention of a
successful settings snapshot after a failed import.

Also manually verify Create Editable Copy: its prefab dependency list should not
include the source `.meshy`, editing copied materials must survive source
reimports, and repeated copies must use distinct folders. The command checks for
remaining source dependencies before reporting success.
